# Security policy

## Supported versions

We fix security problems in the newest minor version of each package.

## Report a problem

Report each problem privately. Do not open a public issue.

1. Open the repo's "Security" tab on GitHub.
2. Select "Report a vulnerability".
3. Describe the problem, the affected package and version, and the steps to reproduce it.

You can also email {{SECURITY_EMAIL}}.

## What happens next

- We reply within 3 working days (SEC-8).
- We confirm the problem and agree on a disclosure date with you.
- We aim to release a fix within 30 days for a high or critical problem.
- We credit you in the release notes, unless you ask us not to.

## Problems in NIPOST's systems

This policy covers Gatepost code only. Report a problem in NIPOST's systems to security@nipost.gov.ng. Do not test NIPOST's systems. NIPOST's acceptable use policy forbids probing them.
